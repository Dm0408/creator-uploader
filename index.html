DM Creator Uploader

DM Creator Uploader is a private, internal desktop tool used by a single independent creator in the Republic of Korea, the owner of the BAMTTOGAK and HUSHVORI YouTube channels to upload videos the owner produces to the owner's own YouTube channels.

What it does

  • Signs in with Google OAuth 2.0 to the creator's own channels (BAMTTOGAK, HUSHVORI, and a children's history channel).
  • Uploads finished video files with title, description, tags, category and "made for kids" setting (videos.insert).
  • Optionally sets a custom thumbnail (thumbnails.set).
  • Scheduled publishing: the goal is to set the publish time (status.publishAt) so videos go live when each channel's viewers are most active. Until this project passes the YouTube API compliance audit, uploads stay private and the publish time is set manually in YouTube Studio.

Who can use it

The tool is not offered to the public. It runs only on the owner's own PC and only accesses channels owned by the owner. No other users' data is accessed.

DM Creator Uploader (한국어)

DM Creator Uploader는 대한민국의 개인 크리에이터(밤또각·HUSHVORI 채널 운영자)가 직접 만든 영상을 본인 소유의 YouTube 채널에 올리기 위해 사용하는 개인용 내부 데스크톱 도구입니다.

하는 일

  • Google OAuth 2.0으로 본인 채널(밤또각, HUSHVORI, 어린이 역사 채널)에 로그인합니다.
  • 완성된 영상 파일을 제목, 설명, 태그, 카테고리, 아동용 여부와 함께 업로드합니다(videos.insert).
  • 필요하면 맞춤 썸네일을 설정합니다(thumbnails.set).
  • 예약 게시: 시청자가 가장 많은 시간에 공개되도록 게시 시각(status.publishAt)을 설정하는 것이 목표입니다. YouTube API 규정 준수 감사를 통과하기 전까지는 비공개로만 올리고, 게시 시각은 YouTube Studio에서 직접 설정합니다.

사용자

이 도구는 일반에 제공되지 않습니다. 소유자의 PC에서만 실행되며 소유자의 채널에만 접근하고, 다른 사용자의 데이터에는 접근하지 않습니다.
