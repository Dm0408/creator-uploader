Privacy Policy

Last updated: 2026-10-21

This policy explains how DM Creator Uploader ("the tool") handles data. The tool uses YouTube API Services. By using the tool you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

1. Who uses the tool

The tool is used only by its owner to manage the owner's own YouTube channels. It is not offered to other people.

2. Data accessed through YouTube API Services

  • OAuth access and refresh tokens for the owner's Google account, with the scopes https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube (the latter is used only to set thumbnails and check the status of videos the tool uploaded).
  • IDs and processing status of videos the tool uploads.

3. How the data is used

Only to upload the owner's own videos, set their metadata and thumbnails (and, after the compliance audit, their scheduled publish time), and confirm that the upload succeeded. The data is not used for advertising, profiling or analytics, and is not sold.

4. Storage

  • OAuth tokens are stored only on the owner's PC, in a local folder outside any shared or synced location. They are never sent anywhere except to Google.
  • Video IDs and upload logs are kept in local text files on the owner's PC. Data obtained from YouTube API Services is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • No YouTube API data is stored on any server operated by the tool.

5. Sharing

Data is not shared with any third party. Video files and metadata are sent only to YouTube.

6. Revoking access and deleting data

You can revoke the tool's access to your Google account at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After access is revoked, locally stored tokens and API data are deleted within 30 days. You can also ask for deletion through GitHub Issues; requests are completed within 7 days.

7. Cookies

The tool is a desktop program and does not use cookies or tracking. This website does not use cookies or analytics.

8. Changes and contact

Changes to this policy will be posted on this page with a new date. Contact: GitHub Issues.

개인정보처리방침 (한국어)

최종 수정일: 2026-10-21

이 방침은 DM Creator Uploader(이하 '도구')가 데이터를 처리하는 방법을 설명합니다. 도구는 YouTube API 서비스를 사용합니다. 도구를 사용하면 YouTube 서비스 약관에도 동의하게 되며, Google의 데이터 처리는 Google 개인정보처리방침에 따릅니다.

1. 사용자

도구는 소유자만 본인 YouTube 채널 관리를 위해 사용합니다. 다른 사람에게 제공하지 않습니다.

2. YouTube API 서비스로 접근하는 데이터

  • 소유자 Google 계정의 OAuth 액세스·갱신 토큰(권한 범위 youtube.upload와 youtube. 후자는 도구가 올린 영상의 썸네일 설정과 상태 확인에만 사용)
  • 도구가 올린 영상의 ID와 처리 상태

3. 이용 목적

소유자 본인의 영상을 업로드하고, 메타데이터·썸네일(감사 통과 후에는 예약 게시 시각)을 설정하고, 업로드 성공 여부를 확인하는 데만 씁니다. 광고, 프로파일링, 분석에 쓰지 않으며 판매하지 않습니다.

4. 보관

  • OAuth 토큰은 소유자 PC의 공유·동기화되지 않는 로컬 폴더에만 저장하며, Google 외에는 어디에도 보내지 않습니다.
  • 영상 ID와 업로드 기록은 소유자 PC의 로컬 파일에 보관합니다. YouTube API 서비스로 받은 데이터는 YouTube API 서비스 개발자 정책에 따라 30일 이내에 갱신하거나 삭제합니다.
  • 도구가 운영하는 서버에는 YouTube API 데이터를 저장하지 않습니다.

5. 제3자 제공

데이터를 제3자와 공유하지 않습니다. 영상 파일과 메타데이터는 YouTube에만 전송합니다.

6. 접근 권한 해제와 삭제

Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 언제든 도구의 접근 권한을 해제할 수 있습니다. 해제 후 로컬에 저장된 토큰과 API 데이터는 30일 이내에 삭제합니다. GitHub Issues로 삭제를 요청하면 7일 이내에 처리합니다.

7. 쿠키

도구는 데스크톱 프로그램으로 쿠키나 추적 기술을 쓰지 않습니다. 이 웹사이트도 쿠키나 분석 도구를 쓰지 않습니다.

8. 변경과 문의

방침이 바뀌면 새 날짜와 함께 이 페이지에 게시합니다. 문의: GitHub Issues
